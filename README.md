# 💍 Wedding Planner & Dashboard

An interactive, responsive web application designed to help couples plan, organize, and budget for their wedding day seamlessly. Built using HTML/CSS/JavaScript and deployed via Streamlit Community Cloud.

- **GitHub Repository:** [https://github.com/kapadewaletayyaba-ctrl/wedding](https://github.com/kapadewaletayyaba-ctrl/wedding)

---

## ✨ Features

- **Interactive Dashboard:** High-level summary of upcoming events, vendor statuses, and budget metrics.
- **Budget Tracker:** Manage and organize expenses dynamically.
- **Guest List Manager:** Track RSVPs and guest counts efficiently.
- **Vendor Management:** Keep vendor contact details and services organized in one place.
- **Event Timeline:** Interactive schedule for all wedding activities.

---

## 🛠️ Project Structure

- `streamlit_app.py` - Main Streamlit entry point embedding the HTML/CSS/JS frontend.
- `index.html` - UI structure for the dashboard components.
- `style.css` - Custom styling and theme definitions.
- `script.js` - Client-side interactivity and event listeners.
